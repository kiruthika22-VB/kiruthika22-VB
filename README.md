# Fake News Detection 📰

## Project Description
This project detects whether news is REAL or FAKE using Machine Learning / Deep Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn / TensorFlow
- NLP

## How it works
1. Input news text
2. Model processes text
3. Output: FAKE or REAL

## Output Example
Fake News Detection model predicts:
- FAKE ❌
- REAL ✅
